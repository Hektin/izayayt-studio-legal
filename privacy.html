Privacy Policy

IZAYAYT Studio · Last updated: November 19, 2026

1. What IZAYAYT Studio is

IZAYAYT Studio is a personal desktop application that runs on the user's own Windows computer. It helps the user prepare short vertical videos and send them, at the user's request, to the user's own TikTok account as a draft (through the TikTok Content Posting API) and, optionally, to the user's own YouTube channel. The developer does not operate any server or online service for this application.

2. Information the application handles

  • TikTok authorization: when the user connects their TikTok account, the application receives an access token, a refresh token and the user's TikTok open ID. These are stored only in a local file on the user's computer.
  • Videos and captions: video files, titles and hashtags that the user prepares are stored locally on the user's computer and are sent to TikTok only when the user chooses to send them.
  • Optional YouTube authorization: if the user chooses to connect YouTube, the corresponding token is likewise stored only locally.

The application does not collect analytics, does not use advertising or tracking technologies, and does not create user accounts of its own.

3. How the information is used

The information is used only to perform the actions the user requests: connecting the user's account, uploading the selected video to TikTok (as a draft that the user reviews and publishes inside the TikTok app), and checking the status of that upload.

4. Sharing

The developer does not receive, sell, rent or share any user data. Data leaves the user's computer only when the application communicates directly with TikTok (and, if enabled by the user, YouTube) in order to perform the actions described above. Those services process the data under their own privacy policies.

5. Retention, deletion and control

  • All data is stored locally and stays until the user deletes it. Deleting the application's data folder removes all stored tokens, videos and captions.
  • The user can revoke the application's access at any time in the TikTok app under Settings and privacy → Security & permissions → Apps and services, or by disconnecting inside the application.

6. Children

The application is not directed to children under 13 and is not intended for use by them.

7. Changes to this policy

This policy may be updated from time to time. The "Last updated" date above shows when it last changed.

8. Contact

Questions about this policy can be sent by opening an issue on this project's GitHub page.
